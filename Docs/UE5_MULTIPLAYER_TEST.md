# UE 5.4 multiplayer milestone
Use a UE 5.4 source build with dedicated-server support and matching C++ toolchain. Generate project files and compile GggEditor and GggServer (Win64 Development). Create and save a test level, configure GggGameMode, add two PlayerStarts. In editor Play settings choose two players, Play As Client and a separate dedicated server. Verify both clients spawn and movement replicates. Invoke GrantReward only from trusted server gameplay logic; verify XP, gold and rank on clients. Rewards are not yet wired to enemy death and are not persistent. For standalone testing cook/package the map for Windows client and server, launch GggServer.exe /Game/Maps/TestMap -log -port=7777 (replace map path with actual saved map), then connect clients using open 127.0.0.1:7777. Do not expose an untested server publicly. Android clients need a separately packaged build and reachable server. No load capacity has been measured. Next: secure combat reward integration, persistence, authentication, world partition and regional server instances.
