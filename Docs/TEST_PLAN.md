# Release gates
- Compile editor and game targets.
- Test two clients in PIE with a dedicated server.
- Verify server-only inventory grants and quest progress.
- Test movement, attack cooldown, collision, disconnects and reconnects.
- Implement authentication, persistence, rate limiting, deployment and monitoring before public access.
- Measure server frame time, bandwidth and database latency at staged load levels; no concurrency capacity is certified.
